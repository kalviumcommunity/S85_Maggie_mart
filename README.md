Project Title:  
MaggieMart  

 Project Overview:  
This project focuses on building a web app for hostel residents to order Maggie (instant noodles) easily. The platform allows users to register, browse available Maggie., and place orders for delivery or pickup. Hostel residents can also see live availability. The goal is to streamline the process of selling Maggie in hostels, ensuring everyone gets their favorite midnight snack hassle-free.  

Key Features:  
1. User Authentication: Secure sign-up and login with email and password.  
2. Product Listings: Displays Maggie options with variations like  size, and pricing.  
3. Order Placement: Users can order Maggie by specifying quantity, delivery location (room number).  
4. Admin Dashboard: For sellers to update availability, process orders, and manage inventory.  
5. Notifications: Users receive order confirmations and updates via in-app notifications or email of availability.  

 Tech Stack:  
- Frontend: React (with Vite for setup), Tailwind CSS for styling.  
- Backend: Node.js with Express for API development.  
- Database: MongoDB for storing user accounts, product details, and order history.  
- Authentication: Firebase Auth or custom authentication using bcrypt and JWT.  
- Deployment: Frontend on Netlify or Vercel, Backend on Render or AWS.  

Why This Project?  
This project was chosen because it addresses a fun, practical need in hostel life—making Maggie accessible to everyone during late-night hunger pangs. It’s both engaging and challenging, allowing for the integration of real-world features like inventory management and order tracking.  
By working on this project, I will gain hands-on experience with:  
- Full-stack web development using React, Node.js, and MongoDB.  
- Implementing secure user authentication and role-based access (user/admin).  
- Designing intuitive UI components for browsing and ordering.  
- Creating APIs for managing orders, products, and inventory.  
- Deploying a scalable and responsive web app.
